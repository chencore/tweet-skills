# 推文口语化改写

## 必须消除

| 原表达 | 替换为 |
|--------|--------|
| 总的来说 / 综上所述 | 直接删 |
| 值得注意的是 | 但你可能没注意到 |
| 不可否认 | （直接删，用事实说话） |
| 一方面...另一方面 | 拆成两个短句 |
| 被动语态 | 改主动 |
| 因此 / 故而 | 所以 / 这意味着 |
| 鉴于 / 基于此 | 因为 / 说白了就是 |
| 不难发现 | 你会发现 |
| 深入分析 | 看看数据 |
| 业内人士认为 | 有人觉得 |

## 必须加入

- 口语连接词（适量）：其实、说白了、问题是、换句话说、关键是
- 短句为主（10-15字一句），偶尔一个长句制造节奏感
- 用「你」而不是「用户」「读者」「大家」
- 可以有语气词（少量）：啊、呢、吧、嘛

## 风格检查清单

改写完成后逐项检查：

- [ ] **大声朗读测试**：读出来像在跟朋友聊天吗？
- [ ] **删减测试**：有没有可以删掉还不影响意思的词？
- [ ] **判断测试**：有明确的个人判断吗？还是四平八稳？
- [ ] **真人测试**：看起来像真人写的吗？不像AI生成物？
- [ ] **结尾测试**：结尾让人想做点什么吗（回复/转发/思考）？

## 改写示例

**原文（AI味）：**
> 不可否认，Muse Spark在Arena排行榜上取得第三名的成绩确实值得关注。然而，深入分析其各项评测数据后不难发现，该模型在抽象推理等方面仍存在明显不足。

**改写后（真人味）：**
> Muse Spark 排 Arena 第三，听着很猛。但你看它抽象推理才42.5分，头部模型76分。排名会骗人，分数不会。
