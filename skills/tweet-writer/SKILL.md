# 推文写作

## 10 种风格

| # | 风格 | 特点 |
|---|------|------|
| 1 | 震撼型 | 强对比、强冲击、开头就炸 |
| 2 | 老程序员碎碎念 | 极致口语化、情绪爆炸、感叹号狂用 |
| 3 | 反直觉型 | 先说反话再翻转，制造认知冲突 |
| 4 | 数据说话型 | 只列数据不评论，让数据自己说话 |
| 5 | 简洁犀利型 | 一句话说透，不超过3句 |
| 6 | 提问互动型 | 抛问题引讨论，留空间不堵死 |
| 7 | 行业分析型 | 拆解逻辑链条，信息密度高 |
| 8 | 对比反差型 | 过去vs现在 / A vs B / 表象vs真相 |
| 9 | 预言型 | 大胆判断+理由，有风险但有传播力 |
| 10 | 工具推荐型 | 实用导向，可操作 |

## 写作规则

- 默认生成10个风格版本
- 每条推文控制在 280 字以内
- 开头3句内必须说明"为什么值得看"
- 结尾要有明确的互动引导或观点收束
- **不写**套话和AI味重的表达
- **不写**"总的来说""综上所述""不可否认"
- **不写**企业风格文案
- 每个自然段只表达一个重点
- 有明确的个人判断，不骑墙

## 口语化要求

- 读出来像在跟朋友聊天
- 短句为主
- 用「你」而不是「用户」「读者」
- 可以用口语连接词：其实、说白了、问题是
- 避免书面语：因此、鉴于、基于此

## 输出格式

```
1️⃣ **[风格名]**
[推文正文]

2️⃣ **[风格名]**
[推文正文]

...（10个）
```
