## 提示词万能公式

### 通用结构

```
主体 + 动作 + 场景 + 光线 + 运镜 + 风格 + 画质 + 约束
```

### 必加画质词

```
4K Ultra HD, rich details, cinematic texture, silky smooth, no blur, no ghosting, stable picture
```

### 必加约束词（防变形）

```
stable face, no deformation, normal human structure, natural smooth movements
```

### 运镜术语速查

| 术语 | 效果 |
|------|------|
| Dolly In | 缓慢推近 |
| Pull Back | 缓慢拉远 |
| Truck | 水平横移 |
| Orbit | 环绕拍摄 |
| Tracking Shot | 跟随拍摄 |
| Static Shot | 固定机位 |
| POV | 第一人称视角 |

### 动作描写技巧

- ✅ 优先使用：slow, gentle, continuous, natural, smooth
- ✅ 好的动词组合：slowly turn around, gently raise hand, light steps, slight orbit
- ❌ 避免：exaggerated, high speed, complex multi-person interaction

### 避坑指南

- ❌ 多人复杂互动（打架、拥抱——容易穿帮）
- ❌ 模糊词（"好看的"、"酷的"——AI无法理解）
- ❌ 矛盾要求（"高速运动" + "极其稳定"）
- ❌ 敏感内容（暴力、成人、版权人物）
